# Безопасность

## Что изменено
- CSP переведён с `unsafe-inline` на `script-src 'self'` и отдельный `app.js`.
- Внешние сетевые запросы разрешены только для официального NOAA SWPC feed, необходимого блоку live-data.
- Нет сторонних рекламных скриптов, аналитических трекеров, iframe, WebSocket или внешних библиотек.
- Нет формы входа и сервера с пользовательскими данными.
- Прогресс хранится локально в `localStorage` и не отправляется на сервер.
- Внешние источники лекций открываются с `noopener noreferrer`.
- Контент, введённый пользователем, не вставляется в DOM как HTML; для динамического текста используется `textContent`.
- `object-src`, `base-uri`, `frame-ancestors` и `form-action` ограничены CSP.

## Важное ограничение GitHub Pages
GitHub Pages — статический хостинг. Он не является полноценным сервером для хранения секретов или персональных данных. Поэтому в проект нельзя помещать API-ключи, пароли, токены, приватные данные детей или административные секреты.

## Live-data
Если официальный NOAA endpoint недоступен или вернул некорректный ответ, интерфейс показывает `—`, а не генерирует заменяющее число.

## Сообщение об уязвимости
Если найдена уязвимость, не публикуйте секреты или эксплуатационный код в открытом issue. Для проекта без backend сначала приложите минимальное описание воспроизводимого поведения и укажите затронутый файл/коммит.
