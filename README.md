# Эко. По ту сторону мусора

Интерактивный образовательный сайт для подростков: лекции, региональные кейсы, адаптивная викторина, эко-детектив, челленджи и live-блок с официальными данными.

## Принцип проекта

Сайт учит не только запоминать экологические факты, но и проверять их: кто измерил показатель, когда, каким методом и где опубликованы данные.

Отдельная линия посвящена Ямало-Ненецкому автономному округу: мерзлоте, метану, тундровым экосистемам и оленеводству. Материалы сопровождаются ссылками на научные публикации и открытые данные.

## Архитектура

- `index.html` — только структура интерфейса.
- `styles.css` — визуальная система и адаптивная вёрстка.
- `app.js` — интерактивность, локальный прогресс и загрузка live-data.
- `assets/found-glassware.webp` — фотография из полевого наблюдения, предоставленная автором проекта.
- `SECURITY.md` — модель безопасности и ограничения GitHub Pages.
- `.nojekyll` — отключает Jekyll-обработку статического проекта.

## Данные

Live-показатели не являются «цифрами для красоты». Клиент получает их из NOAA SWPC. При ошибке запроса отображается `—`. Образовательные материалы используют источники, указанные непосредственно в карточках.

## Запуск

Проект рассчитан на GitHub Pages и не требует сборщика или npm. Все файлы должны находиться в репозитории с сохранением структуры папок.
